# svitlo_tetris
# ⚡ Тетріс: графік відключень  Гра-тетріс у дизайні графіка відключень світла ДТЕК.

Гра-тетріс у дизайні графіка відключень світла ДТЕК. Поле 10×24: стовпці 1.1–5.2, рядки по годинах 00-01 … 23-24. Упалі блоки виглядають як перекреслені блискавки.

Працює як **Telegram Mini App** і як звичайний сайт. Це один HTML-файл без збірки та залежностей.

## Можливості

- 7 фігур, обертання з відскоком від стін, тінь-підказка
- Рахунок, рядки, рівні, прискорення, рекорд (зберігається локально)
- Кнопка «Поділитись результатом» зі посиланням на гру та автора
- Інтеграція з Telegram: повний екран, колір шапки, вібровідгук

## Керування

| Дія | Телефон | Клавіатура |
|---|---|---|
| Рух | перетягування / кнопки ◀ ▶ | ← → |
| Повернути | тап по полю / ⟳ | ↑ або X |
| Вниз | ▼ | ↓ |
| Скинути | швидкий свайп вниз / ⤓ | Пробіл |
| Пауза | ⏸ | P / Esc |

## Запуск

Відкрийте `index.html` у браузері. Більше нічого не потрібно.
